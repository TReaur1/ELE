# 工程模板_辊筒线 —— 新架构复制模板

> 母本：`辊筒上位机工程`（四模块定稿架构参照实现）。
> 本模板 = 母本泛化 + **无线上位机链路四机制**（AGENTS 细则15/16/17/18，2026-09-04 定稿）移植。
> 适用：辊筒/输送类"无线上位机 + PLC 有线控制"的纯上位机控制工程（host_driven，无自动工步序列）。

---

## 一、架构速览

四模块分层（SBR_08 主调度统一调用，各层只读写全局变量表、互不直接调用）：

```
sbr_io()      STEP0 物理层: 输入/输出映像纯透传
sbr_con()     STEP1 控制层: 安全锁存/模式/许可/阀与辊筒控制/报警字汇编 (最先算安全)
sbr_host()    STEP2 通讯层: 三级看门狗/防重放/命令处理/RS485转发
sbr_status()  STEP3 状态层: 三色灯蜂鸣/上位机状态区回写 (最后对外呈现)
```

无线适应四机制落点：

| 机制 | 细则 | 位置 |
|---|---|---|
| 命令防重放（host_Send_CmdSeq + con_LastCmdSeq，停止类永不拦截，恢复沿清记忆） | 15 | SBR_host 段1/3/4 |
| 状态即回执（清0回执 + 状态区上报实际输出，上位机不得以"发送成功"为执行依据） | 16 | SBR_host 段3/4 + SBR_status 段3 |
| 超时分层（通讯域 COMM_* 与设备域 CYL_TIMEOUT 分开定值） | 17 | 变量表/VariableTable_const.csv |
| 三级看门狗（降级冻结 / 失联安全停 + 出向心跳独立自增） | 18 | SBR_host 段1/2 + SBR_con 段1(bit3) + SBR_status 段3 |

## 二、复制步骤（新工程开工）

1. **复制**：整目录复制改名（如 `XX线上位机工程`），本说明可删除或保留作内部文档。
2. **改 IO**：`SBR程序块/SBR_io_IO映射.st` 地址对照注释 + 映像赋值 + `变量表/VariableTable_io.csv` 三处同步（X0~X7 急停/安全优先原则不变）。
3. **改机构**：增删执行机构时同步四处——con 表命令记忆量、SBR_host 命令映射段（照段3/4 样式：启动类加降级+序号门控，停止类裸放行）、SBR_con 输出控制段（显式默认 FALSE）、SBR_status 回写段。
4. **改通讯**：`变量表/VariableTable_host.csv` 增删寄存器（D 地址手填，读写区分开），SBR_host 对应段、SBR_status 回写、`通讯字表`（工程设备配置）四者一致。
5. **改驱动**：非 C20 驱动器时改 SBR_host 段8（RTU 寄存器/站号常量）与 SBR_con 段5 脉冲逻辑；无 RS485 设备则整段删除并清 RTU 相关 con/const 行。
6. **急停注销块**（SBR_host 段2.5）：新增命令记忆量必须同步加入清零清单——**漏加 = 急停后旧命令自恢复**。
7. **报警字**：新报警源按位序续编（bit4 起），必须接 FB_AlarmLatch 锁存闭环（细则2），随动类（如降级/断讯）直接 OR 入字。
8. **自检**：`python scripts/ci_check.py` ERROR 清零；核对表↔代码符号一致、急停注销清单、位定义注释三处（con 表/通讯字表/报警汇编）齐全。

## 三、上位机侧配套协议（交给上位机开发）

- 每条**启动类**命令：写参数 → 写 `host_Send_CmdSeq`（+1 递增）→ 写命令字=1；PLC 受理后命令字自动清 0（受理回执），同序号重发不会二次触发。
- **停止/复位类**命令：直接写 1，无序号要求，任何时刻放行。
- 心跳：每秒写一次 `host_Send_Heart`（任意变化值）；同时监控 `host_Rcv_HeartOut`（PLC 每秒自增）。
- 链路质量：轮询 `host_Rcv_CommState`（0 正常 / 1 降级【命令会被冻结，界面置灰】/ 2 断讯）。
- 命令是否生效：以 `host_Rcv_Running/RevRun/CylUp/CylDn` 等**实际状态**为准，不得以"写成功"为依据。

## 四、编码与格式红线（复制后必须保持）

- `.st`/`.md` UTF-8 无 BOM、CRLF；CSV **GBK**、CRLF；行尾勿用编辑器自动转。
- 标识符仅英文（R1），注释全中文；魔法数字一律进常量表（本模板已把速度档/超时常量化）。
- PROGRAM 内零声明（R2）：全部变量在 CSV 表声明；TONR 直调不建实例；新增边沿检测进 `功能块实例.csv`。
- 就地改 GBK/UTF8 原文件用**字节级替换**，禁止解码重写（防 0 字节截断）。
