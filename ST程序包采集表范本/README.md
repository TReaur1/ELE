# ST程序包采集表范本 (6张CSV)

## 用法
1. 复制整个文件夹, 重命名为你的工程名
2. 逐张填写(中文列名, GBK编码, Excel可直接编辑)
3. 不涉及的表留空(只保留表头); 执行机构按类别逐行填, 不属于该机构的列留空
4. 填完交回 opencode/DSH: csv_to_spec.py 转换 -> 设备模型库管线一键生成 ST 程序包

## 各表说明
- 01_工程.csv: 键值两列, 行固定(工程名称/PLC型号/程序原型/接上位机/有HMI/自动启动方式)
  程序原型取值: host_driven(上位机指挥全自动) 或 internal_seq(PLC内部步进框架, 工步见05表)
- 02_输入IO.csv / 03_输出IO.csv: 逐点位一行; 急停须在"是否急停"填"是"
- 04_执行机构.csv: 机构类别 = servo/stepper/motor/cylinder, 各类只填自己相关列其余留空
- 05_工艺步序.csv: internal_seq 型必填(host_driven 可作节拍参考), 生成的 SBR_06 为框架需人工补工步逻辑
- 06_报警参数.csv: 类别 alarm=报警项(锁存需复位填是/否) / const=常量参数
