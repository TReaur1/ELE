## 通用 FB 库（SBR_01，7 + 1）

| FB | 功能 | 关键接口 |
|---|---|---|
| FB_Debounce | 输入滤波 | RawIn/FilterTime → FilteredOut |
| FB_AlarmLatch | 故障锁存 | FaultIn/Reset → Latched |
| FB_CmdHandshake | 命令握手 | Cmd/Done/Timeout/Abort → Latched/Busy/Expired/Aborted |
| FB_TimedAction | 定时动作 | Start/Time/InPos/Limit → Running/Done/Terminated |
| FB_StepperDrive | 步进驱动 | Man*/Auto*/Reset/Stop/Enable → Forward/Backward/Busy/Done/Error |
| FB_Roller | 电辊筒 | RunFwd/RunRev/SpeedLevel/SpeedLow/SpeedMid/SpeedHigh → A/B/Speed |
| FB_TowerLight | 三色灯 | Fault/Auto/Manual/RunOK → Red/Yellow/Green/Buzzer |
| FB_EtherCAT_Axis_ST | 轴控(EtherCAT) | Axis(IN_OUT)+14命令 → AxisStatusData/Absolute_MoveAbsoluteDone |

## 轴控实体模式（R3b）

每伺服一组：命令实体 `Mx_* : AxisControlData`、状态实体 `Mx_*_Status : AxisStatusData`、
FB 实例 `AxisControl_Mx : FB_EtherCAT_Axis_ST`、轴句柄 `Axis_Mx : _sMCAXIS_INFO`。

调用规范：先赋值命令实体，再 `AxisControl_Mx(Axis := Axis_Mx, PowerEnable := Mx_*.PowerEnable, ..., AxisStatusData => Mx_*_Status)`。

## 程序块调用规范（SBR 子程序）

- SBR 子程序在 **main（SBR_08 主调度）** 中以 `sbr_xxx();` 空括号方式调用，**无参数**。
- 子程序名头部前缀为 `sbr_`（小写）。
- 各层只读写全局变量表，互不直接调用；main 按 STEP0~5 顺序依次调用。
- 程序块英文名（R1）映射：

| 程序块 | 英文名(子程序) | 内容 |
|---|---|---|
| SBR_02 | `sbr_io()` | IO 映射 |
| SBR_03 | `sbr_safety()` | 安全回路 |
| SBR_04 | `sbr_mode()` | 模式管理 |
| SBR_05 | `sbr_manual()` | 手动控制 |
| SBR_06 | `sbr_auto()` | 自动控制 |
| SBR_07 | `sbr_axis()` | 轴控制与输出 |
| SBR_08 | main | 主调度 |

调用顺序：`sbr_io(); sbr_safety(); sbr_mode(); sbr_manual(); sbr_auto(); sbr_axis();`
