# 辊筒驱动方案说明（两方案区分）

> 本工程实际采用 **方案一**。本文档同时记录方案二（备选）的架构差异，
> 供现场按硬件条件选用时对照；若切换方案需按下表同步修改程序。

---

## 方案一：驱动器带动电机传动辊筒（本工程采用 ✅）

- **硬件链路**：PLC(H5U) → C20-400HR 直流无刷驱动器 → 无刷电机 → 传动辊筒
- **启停/方向**：PLC 继电器端子
  - Y10 `out_RollerFwd` → C20 正转端子 FWD
  - Y11 `out_RollerRev` → C20 反转端子 REV（互锁；断开即停机）
- **故障复位**：Y12 `out_RollerRst` → CLR 端子（500ms 脉冲，远程命令触发）
- **速度给定**：RS485 (COM0, Modbus RTU 主站)
  - MB_Master 功能码 06 写 **2001H**，0~3000（单位 1RPM），变化才下发、失败自动重试
- **驱动器侧配置**：F00.01=1(端子指令通道)、F00.02=3(MODBUS 速度给定)、F08.00/F08.01 站号波特率
- **程序载体**：SBR_rtu（MB_Master 收发）、FB_Roller（方向互锁逻辑）、host_Send_RollerSpeed(D27)
- **适用场景**：需要无级调速、速度由上位机在线可调、输送节拍可变

## 方案二：驱动卡直接控制辊筒（备选，本工程未采用）

- **硬件链路**：PLC(H5U) → 辊筒控制卡（正转/反转/多段速等 IO 点直控）→ 辊筒电机
- **启停/方向**：PLC 输出点直控控制卡的运行输入（如 正转 IO / 反转 IO，互斥）
- **速度**：多段速 IO 编码选择（**有级调速**），或控制卡模拟量口
- **复位**：控制卡复位 IO 点脉冲
- **程序形态差异**（若切换需改动）：
  1. 移除 `SBR_rtu` 整块与 RS485 常量（RTU_PORT/INV_ADDR/INV_SPD_REG）
  2. 以虚拟项目先例 `FB_ControlCard`（IO 映射封装）替代 `FB_Roller`
  3. 通讯字表 `host_Send_RollerSpeed`(D27) 改为「多段速档位」整数字段
  4. 变量表 io 增加控制卡对应输出点（正转/反转/各段速）
- **适用场景**：速度固定档位即可满足工艺、成本敏感、现场不便维护通讯参数

---

## 共同安全约定（两方案一致）

- 远程控制允许 `bRemoteEn = bRunOK AND bModeAuto`：手动位/急停/报警/断讯任一不满足 → 辊筒停止
- 命令为触发式+清0回执（D20/D21/D22）；许可丢失强制清残留命令字
- 三色灯蜂鸣随状态指示（报警红+蜂鸣、自动绿、手动黄）
